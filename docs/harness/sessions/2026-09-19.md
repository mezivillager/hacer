## 6. What the session learned

Today's rows are in `docs/harness/ledger.md`. The ones worth remembering:

- **Cancelled duplicate runs block merges.** A required check whose duplicate run was cancelled by `concurrency` blocks the merge even when a later run passed (#295).
- **New integrations switch things on.** Connecting one can enable billed features, so check what it turned on right away.
- **The owner's cost stance.** No usage-billed add-ons: use capacity the subscriptions already include, such as the local `cursor-agent` CLI. Subagents default to Opus, with Sonnet for routine work.
