## R771 — `hacer test` refuses a BUILTIN stand-in for a non-primitive chip
Builds on: none
From #591 (#610). An `.hdl` whose chip under test is `BUILTIN` is refused (exit 1) unless the chip
is one of the reference IDE's seven builtins: Nand, DFF, ARegister, DRegister, Screen, Keyboard,
ROM32K. #610's verifier confirmed that list matches the reference's `BUILTIN_CHIPS`, with RAM16K
excluded because Project 3 builds it.

The reference IDE itself accepts `BUILTIN` for any chip it has a builtin for
(`web-ide/simulator/src/chip/builder.ts:233`). HACER is deliberately stricter: an agent acts on the
exit code, and a flag that still exits 0 would be a one-line green.
Cost if wrong: an agent testing a builtin-only chip is refused until the list gains it, a one-line
change.
