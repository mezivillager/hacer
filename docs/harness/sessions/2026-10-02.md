  `main` into its branch to see a ledger clash; the tool read CLEAN, GitHub answered
  `This branch can't be rebased` three times, and the tool gave up (exit 4), as designed. The same
  two commits were re-opened as #668 from a clean cherry-pick (R790). The finding reaches further:
  #651's stale-green path updates a branch with GitHub's REST `update-branch`, which adds exactly
  such a merge commit, so that path could not have completed. #672 moves it to a `REBASE` update. The new path was then exercised live on the
