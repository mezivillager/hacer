## Context

The web-ide shows a `FullPinout` component with toggleable input pins and read-only output pins. HACER surfaces only aggregate circuit stats today (gate/wire/input/output counts), not pin-level detail in the shell.

Users need to:
- See all chip I/O pins with names, widths, and current values
- Toggle single-bit inputs or enter multi-bit values
- Click an "Eval" button to evaluate the circuit once without continuous simulation
- See output values update in real-time

### Current shell:
HACER now uses `CompactToolbar`, `RightActionBar`, `PropertiesPanel`, `StatusBar`, and `HelpBar` instead of a single sidebar. Add PinoutPanel as a compact section in the right drawer or PropertiesPanel flow, using primitives from `@/components/ui-kit/*`.

### Current node data

- `InputNode` / `OutputNode`: `value: number` (integer signal / bitmask per P05-02). For display parity with 3D, use `formatSignalLabel` from `@/simulation/signalDisplay` where appropriate.
- `updateInputNodeValue(nodeId, value: number)` in `src/store/actions/nodeActions/nodeActions.ts`
- `circuitActions.simulationTick()` in `src/store/actions/simulationActions/simulationActions.ts` (topological evaluation; P05-03)

**In-scene readability:** Small 3D text and preview contrast are addressed in **P05-29**, not this ticket.

## Files to Create/Modify

### `src/components/ui/PinoutPanel.tsx`

```tsx
import { useCircuitStore } from '@/store/circuitStore'
import { circuitActions } from '@/store/circuitStore'
import { Button } from '@/components/ui-kit/button'
import { Separator } from '@/components/ui-kit/separator'

export function PinoutPanel() {
  const inputNodes = useCircuitStore(state => state.inputNodes)
  const outputNodes = useCircuitStore(state => state.outputNodes)

  const handleToggle = (nodeId: string, currentValue: number) => {
    const newValue = currentValue ? 0 : 1
    circuitActions.updateInputNodeValue(nodeId, newValue)
  }

  const handleEval = () => {
    circuitActions.simulationTick()
  }

  if (inputNodes.length === 0 && outputNodes.length === 0) {
    return null
  }

  return (
    <div data-testid="pinout-panel" style={{ padding: '8px 0' }}>
      <div style={{ fontWeight: 600, fontSize: 12, marginBottom: 6 }}>Chip I/O</div>
      <Separator className="my-2" />

      {inputNodes.length > 0 && (
        <div data-testid="pinout-inputs">
          <div style={{ fontWeight: 600, fontSize: 11, marginBottom: 4, color: '#888' }}>INPUTS</div>
          {inputNodes.map(node => (
            <div
              key={node.id}
              data-testid={`pin-input-${node.name}`}
              style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', padding: '2px 0' }}
            >
              <span style={{ fontSize: 12 }}>{node.name}{node.width > 1 ? `[${node.width}]` : ''}</span>
              <span
                style={{ cursor: 'pointer', fontFamily: 'monospace', fontSize: 12 }}
                onClick={() => handleToggle(node.id, node.value)}
                data-testid={`pin-toggle-${node.name}`}
              >
                {String(Number(node.value))}
              </span>
            </div>
          ))}
        </div>
      )}

      {outputNodes.length > 0 && (
        <div data-testid="pinout-outputs">
          <div style={{ fontWeight: 600, fontSize: 11, marginBottom: 4, marginTop: 8, color: '#888' }}>OUTPUTS</div>
          {outputNodes.map(node => (
            <div
              key={node.id}
              data-testid={`pin-output-${node.name}`}
              style={{ display: 'flex', justifyContent: 'space-between', padding: '2px 0' }}
            >
              <span style={{ fontSize: 12 }}>{node.name}{node.width > 1 ? `[${node.width}]` : ''}</span>
              <span style={{ fontFamily: 'monospace', fontSize: 12 }}>
                {String(Number(node.value))}
              </span>
            </div>
          ))}
        </div>
      )}

      <Button
        size="small"
        onClick={handleEval}
        style={{ marginTop: 8, width: '100%' }}
        data-testid="eval-button"
      >
        Eval
      </Button>
    </div>
  )
}
```

### `src/components/ui/PinoutPanel.test.tsx`

```typescript
import { describe, it, expect, beforeEach } from 'vitest'
import { render, screen, fireEvent } from '@testing-library/react'
import { useCircuitStore, circuitActions } from '@/store/circuitStore'
import { PinoutPanel } from './PinoutPanel'

beforeEach(() => {
  circuitActions.clearCircuit()
})

describe('PinoutPanel', () => {
  it('renders nothing when no nodes exist', () => {
    const { container } = render(<PinoutPanel />)
    expect(container.firstChild).toBeNull()
  })

  it('lists input nodes with names and values', () => {
    const s = useCircuitStore.getState()
    s.addInputNode('a', { x: 0, y: 0, z: 0 })
    s.addInputNode('b', { x: 0, y: 1, z: 0 })
    render(<PinoutPanel />)
    expect(screen.getByTestId('pin-input-a')).toBeTruthy()
    expect(screen.getByTestId('pin-input-b')).toBeTruthy()
  })

  it('lists output nodes with names and values', () => {
    const s = useCircuitStore.getState()
    s.addOutputNode('out', { x: 0, y: 0, z: 0 })
    render(<PinoutPanel />)
    expect(screen.getByTestId('pin-output-out')).toBeTruthy()
  })

  it('toggling input updates store value', () => {
    const s = useCircuitStore.getState()
    const node = s.addInputNode('a', { x: 0, y: 0, z: 0 })
    // New input nodes initialize to value 1; set to 0 so we can verify the toggle to 1.
    circuitActions.updateInputNodeValue(node.id, 0)
    render(<PinoutPanel />)
    fireEvent.click(screen.getByTestId('pin-toggle-a'))
    const updated = useCircuitStore.getState().inputNodes.find(n => n.id === node.id)
    // Value should flip from 0 to 1
    expect(Number(updated?.value)).toBe(1)
  })

  it('Eval button triggers simulationTick', () => {
    const s = useCircuitStore.getState()
    s.addInputNode('a', { x: 0, y: 0, z: 0 })
    // Add a gate and wire to make simulation meaningful
    const gate = s.addGate('NOT', { x: 2, y: 0, z: 0 })
    s.addOutputNode('out', { x: 4, y: 0, z: 0 })
    // Wire input to gate, gate to output...

    render(<PinoutPanel />)
    fireEvent.click(screen.getByTestId('eval-button'))

    // After eval, output should reflect the computation
    // (exact assertion depends on wiring setup)
  })

  it('shows bus width annotation for multi-bit nodes', () => {
    const s = useCircuitStore.getState()
    s.addInputNode('in', { x: 0, y: 0, z: 0 }, 16)
    render(<PinoutPanel />)
    expect(screen.getByTestId('pin-input-in').textContent).toContain('[16]')
  })
})
```

## Pitfalls

- **UI primitives in tests**: Prefer rendering the real `@/components/ui-kit/*` primitives; add focused mocks only when a Radix interaction primitive requires it.
- **`value` type:** `InputNode` / `OutputNode` use **`number`** (P05-02). Use `Number(node.value)` for numeric assertions; display with `String(Number(node.value))` or `formatSignalLabel` when matching 3D.
- **`updateInputNodeValue`:** Accepts `number`; toggle single-bit with `currentValue ? 0 : 1`.
- **Truth table:** Out of scope for P05-10 (see gap-analysis GAP-UI-3 item 4). Optional later: capped truth table for small `n` inputs.
- **Panel width:** The right drawer is compact (`PANEL_WIDTH = 280`). Keep labels short, values monospace, padding tight.
- **React Compiler:** No `useMemo`, `useCallback`, `React.memo`. Use `useCircuitStore` selectors.
- **Multi-bit editing:** Goal item 4 covers basic numeric input for multi-bit nodes (a plain `<input type="number">` is sufficient). Full bit-toggle matrix and format selector (hex/bin/dec) are deferred to **P05-13**.
- **`simulationTick` for Eval:** One call runs full combinatorial eval (P05-03 topological sort).
