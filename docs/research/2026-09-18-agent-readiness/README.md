# Agent-readiness research (2026-09-18)

Why HACER is being restructured so AI agents can develop it with little oversight, and how.

- `REPORT.md` — diagnosis, what the research says, target shape, goal posts G0–G7, owner decisions.
- `WORK-SYSTEM.md` — the work system: `docs/portfolio.md` + GitHub Issues, the pick rule, PR budget, checks, merge tiers, `ha-prompt-it` v2.
- `DECISIONS.md` — every judgment call taken on the owner's behalf, with cost-if-wrong and revert path.

The seven raw research tracks and the two reviews of the draft are kept in the run directory outside the repo (they contain machine-specific paths); the report cites what it uses from them.
