## 6. Rulings made for the owner, with their cost if wrong

Full text, R301–R351, is in the run's own notes; these are the ones a later session would otherwise
have to reconstruct.

- **The spikes ran before the ADR** (R301), although GitHub did not block it. Fixing the `layout` /
  `route` / `describeScene` contracts before the importer's hard cases and a measured headless
  placement were known would have been exactly the mistake the spike rule exists to stop. Cost if
  wrong: the ADR starts a few hours later. It is the decision the whole day turned on.
- **`order: 'id'` was settled by measurement while the throwaway code still existed** (R313, R318).
  The ADR named it its own weakest decision and proposed to settle it later by rasterising drawings
  and judging by eye. The first review pointed out that a cheaper experiment already existed in two
  spike trees that were about to be deleted. It was run, and it **overturned the ADR's headline
  decision**: id order costs **2–3× the crossings** on every real fixture (Parity5 50 vs 0; 906
  nodes 42 696 vs 13 475), and its claimed 100 % stability is an artefact of `addPart` appending —
  under a mid-list id it holds **70 %**, *below* barycentre's 91–95 %.

  considered — is byte-identical to barycentre on the first layout and at least as stable on every
  edit shape measured. Cost if wrong: drift over very many successive edits (1 650 → 2 384 over ten
  additions) is the open question, and the delta review was asked what happens over a hundred.

## 7. What the session learned

Today's rows are in `docs/harness/ledger.md`. The ones worth remembering:

- **A criterion is prose until someone opens the file it names.** Three times today an acceptance
  criterion or a recommendation asserted a measured fact that the artefact did not support, and each
  time a builder or a verifier spent effort discovering it. The rule already exists for issue bodies;
  what was missing is applying it to the coordinator's own comments and briefs. **This is the run's
  main process lesson and it has no mechanism yet.**
- **A property test must be shown failing against the defect it describes.** #362's builder wrote a
  permutation property over slice-assembled signals, then checked it against the *unfixed* compiler:
  with every writer at the same dependency depth it found **0 of 400** wrong permutations, because
  Kahn's queue drains them before the reader whatever the source order. Mixing the depths gave
  105/400. A green property test with a vacuous generator is indistinguishable from a passing one.
- **Rerunning cancelled workflow runs in a batch makes it worse.** Each rerun contends with its
  sibling under the same `concurrency` group: measured on #362, **one cancellation became three**.
  The coordinator's own written recovery advice was the cause. One at a time, waiting for each.
- **A spike's throwaway code is evidence with an expiry date.** The measurement that overturned the
  ADR's headline decision cost minutes only because both spikes' trees still existed. The cheap
  window closes when the tree is collected — so run the comparison *then*, and commit the raw output
  beside the note, because its producer is about to be deleted.
- **Two of three ADR passes changed a decision, and neither finding came from re-reading.** One
  invented an option the document never considered; the other ran the document's own claim against
  the merged engine and found it false. An adversarial review that only re-reads is worth much less
  than one that runs something.
- **A PR that absolves itself is the claim least likely to be checked** — and #370's two
  self-assessments ("this is pre-existing", "I did not cause #363") were both *true*, verified by
  running each claimed repro at `origin/main`. Check them anyway; the point is that nobody otherwise
  would.
- **The fix goes to every surface that states the rule, not to the file the blocker named.** The
  same tier-rule ambiguity was reintroduced in `.claude/agents/hacer-verifier.md` in the same commit
  that fixed `verifier-brief.md`, and again a round later. Pinning more phrases would not have caught
  it, because the defect is **divergence between twins**: the load-bearing check is that the two
  files carry the *same sentence* (#391).
- **When two agents must touch one file, the second states its assumption on the first's issue.**
  That is why the #370/#375 collision cost one predicted line instead of a rewrite.
